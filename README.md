# Производственная практика

Каждый из участников занимался разработкой конвертации свёрточной модели, в частности, Yolo11n, Yolo8n, MobileNetV2.

## Цели:
* Научиться конвертировать модели в формат RKNN для дальнейшего тестирования на одноплатный компьютер Orange Pi 5B (8gb, rk3588s);
* Реализовать алгоритм построения конвертации для каждой модели;
* Сохранить и улучшить качество метрики упрощенной модели после конвертации;
* Ускорить процесс конвертации модели.

Задачи для выполнения цели были поставлены индивидуально.
